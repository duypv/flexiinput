Features

Everything Flexi Input does today. The list is intentionally short — the app is meant to do one thing well.

Per-device button remapping

Every connected mouse appears in the device list. Toggle remapping on for a device, then bind any of its side-buttons (button 3 and above) to a keyboard shortcut. Bindings are stored per device, so unplugging and reconnecting the same mouse restores its layout.

Hotkey recording

Click Record, press the shortcut, click Save. The shortcut must include at least one modifier (Cmd, Ctrl, Option, or Shift) to avoid accidental remaps of plain letters. The recorder shows a live preview using the same notation macOS uses in menus.

Click swallowing

When a button is bound, the original click never reaches the foreground app — Flexi Input intercepts it via CGEventTap and posts the bound key combo instead. Unbound buttons pass through unchanged.

Natural scroll toggle

A single switch in the device list reverses the scroll-wheel direction for every mouse while the app is running. Useful when macOS's global setting affects your trackpad in the wrong direction.

Lightweight

  • Menu bar only — no Dock icon, no main window.
  • Pure SwiftUI + AppKit. No Electron. No bundled Chromium.
  • Universal binary — runs natively on Apple Silicon and Intel Macs.
  • No background daemons, no login items, no analytics.

Distribution

Signed with a Developer ID certificate, notarized by Apple, stapled, and shipped as a DMG. Gatekeeper accepts it without the right-click dance.
