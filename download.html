System requirements

  • macOS 14 Sonoma or later
  • Apple Silicon or Intel — universal binary
  • Input Monitoring permission (granted on first launch)
  • Accessibility permission (granted from System Settings)

Install

  1. Download the DMG above.
  2. Open the DMG and drag Flexi Input.app into Applications.
  3. Launch the app from Applications. macOS will prompt for Input Monitoring — grant it.
  4. Open System Settings → Privacy & Security → Accessibility and enable Flexi Input.
  5. Quit and reopen Flexi Input so macOS starts delivering events.

Verify the download

The DMG is signed with a Developer ID certificate and notarized by Apple. To verify manually:

spctl --assess --type open --context context:primary-signature -vv FlexiInput-1.3.1.dmg
codesign -dv --verbose=4 /Volumes/FlexiInput/Flexi\ Input.app
