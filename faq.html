FAQ

The menu bar icon doesn't appear after launch.

If your menu bar is full, macOS may have hidden the icon behind the camera notch on MacBook Pro. Cmd-drag other icons to make room. If that doesn't help, quit any prior copy of Flexi Input first — running two instances at once leaves the second one without a status item.

I press a side-button but nothing happens — and the detection area stays empty.

Flexi Input needs Input Monitoring permission for macOS to deliver HID events. Open System Settings → Privacy & Security → Input Monitoring, enable Flexi Input, then quit and relaunch the app. The detection area will start filling in as soon as macOS routes events again.

The button is detected, but the bound hotkey doesn't fire.

That's the Accessibility permission. Without it the app can't install the event tap that swallows the original click and posts the hotkey. Toggle Flexi Input on under System Settings → Privacy & Security → Accessibility and relaunch.

Why does it need Accessibility access? That sounds invasive.

The only thing Flexi Input does with the Accessibility entitlement is install a CGEventTap on mouse-button events. macOS doesn't expose a more granular permission for that; any app that synthesizes a keyboard shortcut needs the same access. The source code is auditable — Flexi Input does not log keystrokes, take screenshots, or connect to the network.

Can I bind a side-button to a non-keyboard action — like opening an app?

Not directly. Flexi Input only posts keyboard shortcuts. Combine it with a system-wide hotkey from another app (Raycast, Alfred, macOS Shortcuts) to chain to anything you want.

Does it work with Logitech / Razer / wireless mice?

Yes — anything macOS recognizes as a HID mouse appears in the device list. Vendor drivers (Logi Options+, Razer Synapse) sometimes intercept side-buttons before macOS sees them; if your mouse has a vendor driver, configure those buttons to send a generic "Button 4 / 5 / etc." event so Flexi Input can pick them up.

Will my bindings sync across Macs?

Not in this version. Bindings are stored in ~/Library/Preferences/com.cafesg.FlexiInput.plist. You can copy that file across machines, or wait for cloud sync to be added.

Is there auto-update?

The release infrastructure publishes a signed Sparkle appcast at appcast.xml, so once the in-app updater ships, Flexi Input will check for new versions automatically. Until then, watch this site or the changelog page.

How do I uninstall it?

Quit the app from its menu bar icon, drag Flexi Input.app from Applications to the Trash, and remove ~/Library/Preferences/com.cafesg.FlexiInput.plist if you want to wipe stored bindings.
